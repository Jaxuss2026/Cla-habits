# Cla-habit
Here we can modify with AI the product:

Visión:
Quiero una web donde se pueda crear hábitos, y puedas registrar si hoy lo has cumplido o no, además pueds visualizar el progreso que haz hecho a traves de:
- Un registro general que contenga el n° de habitos actual, y un % de completados, además de un filtro por tiempo de los hábitos.
- Un registro por hábito con gráficas en diferentes tiempos, por dias, semanas, meses.
- Un registro diario donde marcar hábitos.
- Un registro mensual de cuales son los hábitos realizados.
- Los hábitos no se eliminan, solo se desvinculan e incluso se pueden recuperar.

  Esa es mi visión para el nuevo proyecto.
